# QA - Visión general

La cobertura de QA es **transversal a todas las entregas**. Cada entrega tiene
su propia carpeta en el repositorio `cqrs-qa`, con casos diseñados a partir
del contrato de API + Stored Procedures definido en el kickoff de esa entrega.

## Qué se publica aquí

Esta sección de Docusaurus muestra el **resultado y estado de cobertura** de
cada entrega: qué se probó, qué pasó y qué quedó pendiente.

El detalle interno de ejecución (pasos, datos de prueba, capturas, bugs) vive
en el repositorio [`cqrs-qa`](https://github.com/Riwi-CQRS/cqrs-qa).
